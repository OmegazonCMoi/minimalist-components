# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.3.x | Yes |
| < 0.3 | No |

## Reporting a vulnerability

Please open a private [GitHub security advisory](https://github.com/OmegazonCMoi/minimalist-components/security/advisories/new) or email the maintainer listed on npm.

Do not open a public issue for security reports.
